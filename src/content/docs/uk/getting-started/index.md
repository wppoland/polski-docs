## Що таке Polski for WooCommerce?

**Polski for WooCommerce** - це безкоштовний плагін із відкритим кодом (GPLv2) від [wppoland.com](https://wppoland.com). Він адаптує магазин WooCommerce до польських норм і стандартів e-commerce. Містить понад 30 модулів: правові вимоги, ціни, касу, продукти харчування, функції магазину та інструменти для розробників.

Поточна версія: **1.3.2**

### Системні вимоги

Перед встановленням переконайтеся, що ваш сервер відповідає мінімальним вимогам:

| Вимога | Мінімальна версія |
|-----------|-----------------|
| WordPress | 6.4 або новіший |
| WooCommerce | 8.0 або новіший |
| PHP | 8.1 або новіший |
| MySQL | 5.7 або новіший / MariaDB 10.3+ |

:::tip[Рекомендація]
Для найкращої продуктивності рекомендуємо PHP 8.2+ та WooCommerce 9.x. Плагін регулярно тестується з найновішими версіями WordPress і WooCommerce.
:::

## Огляд модулів

Плагін працює модульно - ви вмикаєте лише те, що вам потрібно. Нижче ви знайдете опис усіх груп модулів.

![Панель модулів Polski for WooCommerce](../../../../assets/screenshots/screenshot-1-modules-dashboard.png)

### Правові вимоги

Модулі для виконання вимог польського та європейського права:

- **GPSR (безпека продуктів)** - дані виробника, імпортера та відповідальної особи на картках товарів
- **Omnibus** - найнижча ціна за 30 днів до знижки
- **Право на відмову** - форми повернень і документи про відмову
- **GDPR** - згоди, анонімізація даних, реєстр обробки
- **DSA (Акт про цифрові послуги)** - контактний пункт, повідомлення про контент
- **KSeF** - підготовка до Національної системи е-Фактур
- **Greenwashing** - контроль екологічних заяв
- **Правові сторінки** - регламент, політика конфіденційності та політика повернень

### Ціни та інформація про товар

Модулі для відображення цін і даних про товари:

- **Ціни за одиницю** - автоматичний перерахунок і відображення цін за одиницю виміру (zł/kg, zł/l)
- **Відображення VAT** - інформація про ставку VAT і ціну нетто/брутто
- **Час доставки** - орієнтовний час виконання замовлення на картці товару
- **Дані виробника** - поле виробника, марка, каталожний номер

### Каса та замовлення

Модулі для сторінки каси та процесу замовлення:

- **Кнопка замовлення** - зміна тексту кнопки на "Замовляю з обов'язком оплати" (правова вимога)
- **Правові чекбокси** - налаштовувані згоди на регламент, політику конфіденційності, розсилку
- **Пошук NIP** - автозаповнення даних компанії за номером NIP (API GUS)
- **Подвійне підтвердження** - верифікація електронної адреси (double opt-in)

### Продовольчі товари

Спеціалізовані модулі для магазинів із продуктами харчування:

- **Огляд продовольчих товарів** - спеціальні поля для продуктів харчування
- **Харчова цінність** - таблиця харчової цінності відповідно до регламенту 1169/2011
- **Алергени** - виділені алергени в описі товару (14 основних алергенів)
- **Nutri-Score** - відображення позначки Nutri-Score (A-E)

### Модулі магазину

Функції, що полегшують покупки клієнтам:

- **Список бажань** - збереження товарів на потім
- **Порівняння** - порівняння товарів поруч
- **Швидкий перегляд** - перегляд товару без виходу зі сторінки категорії
- **AJAX-пошук** - пошук товарів у реальному часі
- **AJAX-фільтри** - динамічне фільтрування товарів без перезавантаження сторінки
- **Слайдер товарів** - каруселі товарів із налаштовуваними опціями
- **Значки товарів** - мітки типу "Новинка", "Бестселер", "Останні штуки"
- **Інші модулі** - додаткові функції магазину

### Інструменти

Модулі для керування магазином:

- **Панель відповідності** - огляд стану правових вимог магазину в одному місці
- **Аудит сайту** - автоматична перевірка конфігурації магазину
- **Інциденти безпеки** - реєстр і керування інцидентами GDPR
- **Верифіковані відгуки** - система верифікованих відгуків клієнтів

### Для розробників

Інструменти та API для програмістів:

- **REST API** - ендпоінти для керування даними плагіна
- **Хуки (дії та фільтри)** - понад 100 хуків для розширення функціональності
- **Шорткоди** - готові шорткоди для вбудовування елементів у контент
- **Шаблони** - перевизначення шаблонів плагіна в темі
- **WP-CLI** - команди CLI для керування плагіном із терміналу
- **Імпорт CSV** - масовий імпорт даних про товари
- **Блоки Gutenberg** - спеціальні блоки редактора
- **Schema.org** - автоматичні структуровані дані для товарів

Три кроки до магазину, що відповідає нормам:

- **Модульна структура** - ви вмикаєте лише те, що вам потрібно
- **Правові вимоги** - оновлюються разом зі змінами норм
- **Відкритий код** - вихідний код на GitHub, ліцензія GPLv2
- **Без підписки** - усі функції доступні безкоштовно
