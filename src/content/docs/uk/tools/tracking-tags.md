Менеджер тегів - це опціональний модуль, який в одному місці керує популярними маркетинговими пікселями та аналітичними інструментами. Замість вставляння сніпетів у тему ви вмикаєте потрібних постачальників і вказуєте власний ідентифікатор відстеження або домен. Нічого не зашито жорстко, і плагін ніколи не надсилає жодного HTTP-запиту на боці PHP, кожен тег - це невеликий фрагмент коду на боці браузера, що додається до сторінки.

Найважливіше: кожен тег проходить через Менеджер згод і обгорнутий у елемент `<script type="text/plain" data-polski-consent="КАТЕГОРІЯ">`. Скрипт запускається лише тоді, коли відвідувач надасть згоду на відповідну категорію. Рекламні та ремаркетингові пікселі бронюються категорією `marketing`, а вимірювальні інструменти та теплові карти - категорією `analytics`.

Це інструменти, які допомагають завантажувати теги третіх сторін відповідальним чином. Вони не є юридичною консультацією і самі собою не гарантують відповідності жодним приписам.

## Увімкнення модуля

Модуль **вимкнено за замовчуванням**. Увімкніть його в **WooCommerce > Polski > Модулі** (секція "Менеджер тегів"). Після увімкнення налаштування окремих постачальників знайдете на картці модуля. Тег певного постачальника зʼявляється на фронті лише тоді, коли виконано три умови: модуль увімкнено, постачальника позначено та вписано його ідентифікатор (за винятком Simple Analytics, який не потребує ідентифікатора).

## Що тут не підтримується

GA4 та Google Tag Manager навмисно **не** підтримуються в цьому модулі. Вони підтримуються в модулі **GA4 DataLayer** разом з подіями e-commerce WooCommerce, щоб уникнути подвійного завантаження тих самих скриптів.

## Підтримувані постачальники

Кожен постачальник має власний перемикач увімк/вимк та поле для ідентифікатора. Категорія згоди вирішує, коли тег може запуститися.

### Категорія marketing

| Постачальник                      | Поле ідентифікатора |
| --------------------------------- | ------------------- |
| Meta Pixel                        | Pixel ID            |
| TikTok Pixel                      | Pixel ID            |
| Microsoft Advertising (Bing UET)  | UET Tag ID          |
| LinkedIn Insight                  | Partner ID          |
| Pinterest Tag                     | Tag ID              |
| X / Twitter Ads                   | Pixel ID            |
| Google Ads                        | AW-XXXXXXXXX        |

### Категорія analytics

| Постачальник      | Поле ідентифікатора |
| ----------------- | ------------------- |
| Microsoft Clarity | Project ID          |
| Matomo            | Site ID (а також URL-адреса екземпляра Matomo) |
| Plausible         | Домен (наприклад, example.com) |
| PostHog           | Project API key     |
| Hotjar            | Site ID             |
| Inspectlet        | WID                 |
| Crazy Egg         | Account ID          |
| Simple Analytics  | без ідентифікатора (достатньо перемикача) |

## Робота та порядок завантаження

- Теги виводяться в заголовку сторінки за допомогою `wp_head` (пріоритет 20), тобто після Google Consent Mode та модуля DataLayer.
- Hotjar краще ініціалізується безпосередньо перед `</body>`, тому виводиться в підвалі за допомогою `wp_footer`.
- Теги ніколи не виводяться в адміністративній панелі, вони працюють виключно на фронті магазину.
- Matomo вимагає як Site ID, так і URL-адресу екземпляра Matomo. Без URL-адреси тег не буде виведено.
- Crazy Egg вимагає числовий Account ID завдовжки щонайменше 8 цифр, інакше тег не буде виведено.

## Бронювання згодою

Бронювання згодою працює разом з модулем **Менеджер згод**, який надає шар згоди та зчитує вибір відвідувача. Доки відвідувач не надасть згоду на категорію `marketing` чи `analytics`, обгорнуті скрипти залишаються неактивними і не завантажують жодного коду третьої сторони. Після надання згоди відповідні теги починають працювати.

Памʼятайте, що правильна конфігурація згоди залежить від вашого правового контексту. Плагін надає технічний механізм, а рішення про те, які теги та категорії застосовувати, ви приймаєте самостійно.

## Усунення проблем

**Тег не зʼявляється** - перевірте, чи модуль увімкнено, постачальника позначено, а поле ідентифікатора заповнено. Для Matomo також потрібна URL-адреса екземпляра.

**Тег є в коді сторінки, але нічого не рахує** - це очікувана поведінка, доки відвідувач не надасть згоду на відповідну категорію в Менеджері згод. Скрипт типу `text/plain` запускається лише після згоди.

**Шукаю GA4 або GTM** - вони в модулі GA4 DataLayer, не тут.
