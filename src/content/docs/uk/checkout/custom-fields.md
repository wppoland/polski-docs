Модуль Custom Checkout Fields дозволяє додавати власні поля до форми замовлення WooCommerce.

## Увімкнення

Перейдіть до **WooCommerce > Polski > Moduły** і увімкніть модуль **Custom Checkout Fields** у розділі "Checkout".

## Керування полями

Після увімкнення модуля перейдіть до **WooCommerce > Checkout Fields**, щоб додавати та редагувати поля.

## Доступні типи полів

| Тип | Опис |
|-----|------|
| Text | Текстове поле |
| Textarea | Багаторядкове текстове поле |
| Select | Випадний список |
| Checkbox | Поле вибору |
| Radio | Радіокнопки |
| Number | Числове поле |
| Email | Поле email з валідацією формату |
| Date | Поле дати |
| Phone | Поле телефону |

## Налаштування поля

| Опція | Опис |
|-------|------|
| Увімкнено | Чи активне поле |
| Назва (meta key) | Ключ мета, під яким зберігається значення |
| Етикетка | Текст етикетки, видимий над полем |
| Тип | Тип поля (зі списку вище) |
| Секція | Billing, Shipping або Order notes |
| Обов'язкове | Чи є поле обов'язковим |
| Пріоритет | Порядок відображення (нижчий = раніше) |
| Placeholder | Текст підказки в полі |
| Опції | Для select/radio: одна опція на рядок (значення\|етикетка) |
| Клас CSS | Класи CSS (напр. form-row-wide, form-row-first) |
| Показати в листах | Значення поля в листах замовлення |
| Показати в адмінці | Значення поля в панелі замовлення |
| Показати в Моєму обліковому записі | Значення поля на сторінці замовлення клієнта |
| Умовна доставка | Показувати поле лише для певного методу доставки |

## Опції для Select/Radio

Введіть опції по одній на рядок у форматі:
```
значення|Етикетка
```

Приклад:
```
firma|Компанія
osoba|Приватна особа
```

## Відображення значень

Значення власних полів автоматично відображаються:
- У панелі адміністратора замовлення (під платіжною/доставчою адресою)
- У листах замовлення
- На сторінці "Мій обліковий запис > Деталі замовлення"

## Валідація

- Обов'язкові поля - валідація під час оформлення замовлення
- Поля email - валідація формату адреси
- Значення зберігається як санітизований текст у мета замовлення
