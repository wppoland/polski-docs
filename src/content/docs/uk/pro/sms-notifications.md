---
title: SMS-сповіщення
description: SMS про статус замовлення через SMSAPI.pl і SerwerSMS.pl.
---

Модуль надсилає автоматичні SMS клієнтам під час зміни статусу замовлення.

:::note[Вимоги]
Polski PRO потребує: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+. Акаунт у SMSAPI.pl або SerwerSMS.pl.
:::

## Підтримувані провайдери

| Провайдер | API |
|----------|-----|
| SMSAPI.pl | REST API з токеном Bearer |
| SerwerSMS.pl | REST API з токеном Bearer |

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Polski PRO > SMS**.

| Налаштування | Опис |
|------------|------|
| Провайдер | SMSAPI.pl або SerwerSMS.pl |
| Токен API | Ключ авторизації |
| Назва відправника | Поле FROM (макс. 11 символів) |
| Статуси | Які статуси запускають SMS |
| Шаблон повідомлення | Текст SMS з токенами |

## Токени в повідомленні

| Токен | Опис |
|-------|------|
| `{order_id}` | ID замовлення |
| `{order_number}` | Номер замовлення |
| `{first_name}` | Ім'я клієнта |
| `{last_name}` | Прізвище клієнта |
| `{status}` | Назва нового статусу |
| `{tracking_number}` | Номер відстеження (якщо доступний) |
| `{tracking_url}` | URL трекінгу |
| `{total}` | Сума замовлення |
| `{site_name}` | Назва магазину |

## Сповіщення адміністратора

Опціонально можна увімкнути SMS адміністратору про нові замовлення з окремим шаблоном.

## Нормалізація номера

Система автоматично нормалізує польські телефонні номери до міжнародного формату (48XXXXXXXXX).

## RODO

Телефонні номери маскуються в нотатках замовлення (напр. 501***789).
