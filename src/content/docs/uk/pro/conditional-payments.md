title: Умовні методи оплати
description: Приховування та показ методів оплати на основі методу доставки, вартості кошика, ролі користувача та категорії продуктів.
---

Модуль умовних методів оплати дозволяє контролювати доступність платіжних шлюзів на основі правил.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Polski PRO > Умовні платежі**.

## Типи умов

| Умова | Опис |
|---------|------|
| Метод доставки | Приховати/показати шлюз для конкретного методу доставки |
| Вартість кошика (мін) | Приховати шлюз, коли кошик нижче суми |
| Вартість кошика (макс) | Приховати шлюз, коли кошик вище суми |
| Роль користувача | Шлюз тільки для визначеної ролі (наприклад, wholesale) |
| Категорія продукту | Шлюз доступний, коли в кошику є продукти з категорії |

## Правила

Кожне правило складається з:
- **Платіжний шлюз** - який шлюз охоплено правилом
- **Дія** - `hide` (приховати, коли умова виконана) або `show_only` (показати тільки, коли виконана)
- **Тип умови** - один із наведених вище
- **Значення умови** - наприклад, ID методу доставки, сума, slug ролі

### Приклади

| Шлюз | Дія | Умова | Значення | Ефект |
|--------|-------|---------|---------|-------|
| Накладений платіж (COD) | hide | Метод доставки | inpost_locker | Приховати накладений платіж для Paczkomat |
| Переказ | show_only | Вартість кошика мін | 200 | Переказ доступний від 200 PLN |
| PayPal | hide | Роль користувача | wholesale | Гуртові клієнти не бачать PayPal |

## Плата за метод оплати

Ви можете додати додаткову плату за вибраний метод оплати:

| Налаштування | Опис |
|------------|------|
| Увімкнено | Активує плату для цього шлюзу |
| Назва плати | Текст, видимий у кошику |
| Тип | Фіксована сума або відсоток |
| Сума | Значення плати |
| Мін. замовлення | Плата тільки вище суми |
| Макс. замовлення | Плата тільки нижче суми |
| Підлягає ПДВ | Чи нараховувати ПДВ на плату |
| Податковий клас | Клас ПДВ для плати |

Плата автоматично перераховується при зміні методу оплати на checkout (AJAX).

## Фільтр WooCommerce

Модуль використовує фільтр `woocommerce_available_payment_gateways` з пріоритетом 100 і `woocommerce_cart_calculate_fees` для плат.
