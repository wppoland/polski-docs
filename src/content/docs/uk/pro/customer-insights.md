Модуль Customer Insights забезпечує поглиблений аналіз бази клієнтів з використанням сегментації RFM (Recency, Frequency, Monetary). Панель показує ключові метрики, сегменти клієнтів та рекомендації маркетингових дій.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Як це працює

1. Плагін аналізує історію замовлень усіх клієнтів
2. Для кожного клієнта обчислює три показники RFM:
   - **Recency (R)** - скільки днів минуло від останнього замовлення
   - **Frequency (F)** - загальна кількість замовлень
   - **Monetary (M)** - загальна вартість замовлень
3. На основі показників клієнт призначається до одного з 7 сегментів
4. Результати кешуються в transient на 1 годину

## Панель

Перейдіть до **WooCommerce > Аналіз клієнтів**, щоб відкрити панель.

### Картки підсумку

Угорі панелі відображаються чотири метрики:

| Метрика | Опис |
|---------|------|
| Загальна кількість клієнтів | Усі клієнти щонайменше з одним замовленням |
| Середній CLV | Середня цінність клієнта протягом усього життєвого циклу (Customer Lifetime Value) |
| Середня кількість замовлень | Середня кількість замовлень на клієнта |
| Ризик відтоку | Частка клієнтів без замовлення за останні 30 днів |

### Сегменти RFM

Модуль класифікує клієнтів на 7 сегментів:

| Сегмент | Характеристика | Рекомендація |
|---------|----------------|--------------|
| Champions | Високі R, F та M - купують часто, багато й нещодавно | Нагороджуйте ексклюзивними пропозиціями, пропонуйте програму VIP |
| Loyal | Високе F - купують регулярно | Додатковий продаж (upselling), пропонуйте підписки |
| Potential Loyal | Середнє F, високе R - нещодавно купили кілька разів | Заохочуйте до наступних покупок, будуйте лояльність |
| New Customers | Високе R, низьке F - свіжий клієнт з 1-2 замовленнями | Привітайте, запропонуйте знижку на наступні покупки |
| At Risk | Низьке R, високе F - колись купували часто, тепер припинили | Реактиваційна кампанія, запитайте про причину |
| Hibernating | Низьке R, середнє F - давно не купували | Агресивна пропозиція win-back, обмежені в часі знижки |
| Lost | Дуже низьке R, низьке F - разові клієнти давнього часу | Остання спроба контакту або вилучення з активних кампаній |

### Таблиця сегментів

Панель відображає таблицю-підсумок для кожного сегмента:

| Колонка | Опис |
|---------|------|
| Сегмент | Назва сегмента з кольоровим маркером |
| Кількість клієнтів | Кількість клієнтів у сегменті |
| Частка % | Відсоткова частка сегмента в усій базі |
| Середній дохід | Середня вартість замовлень клієнтів у сегменті |
| Середня кількість замовлень | Середня кількість замовлень на клієнта в сегменті |
| Рекомендація | Запропонована маркетингова дія |

### Топ-клієнти

Під таблицею сегментів відображається список найцінніших клієнтів (Top Customers), відсортований за спаданням за загальною вартістю замовлень. Таблиця містить:

- Імʼя та прізвище клієнта
- Адресу електронної пошти
- Сегмент RFM
- Кількість замовлень
- Загальну вартість замовлень
- Дату останнього замовлення

## Продуктивність

Модуль використовує прямі SQL-запити замість WP_Query для оптимальної продуктивності при великих базах клієнтів:

- Запити виконуються на таблицях замовлень WooCommerce
- Агрегація даних відбувається на рівні бази даних
- Результати кешуються в WordPress transient на 1 годину
- Ключ transient: `polski_pro_customer_insights`
- Час спливання: 3600 секунд

## Увімкнення модуля

Модуль контролюється перемикачем у налаштуваннях модулів PRO:

```
WooCommerce > Налаштування > Polski PRO > Модулі > Customer Insights
```

Після увімкнення модуля пункт **Аналіз клієнтів** зʼявляється автоматично в меню WooCommerce.
