Модуль програми лояльності дозволяє винагороджувати клієнтів балами за покупки та дає змогу обмінювати бали на знижки в кошику.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Polski PRO > Лояльність**.

### Базові налаштування

| Налаштування | Опис | За замовчуванням |
|------------|------|-----------|
| Увімкнено | Активує програму лояльності | Ні |
| Бали за 1 PLN | Скільки балів за кожен злотий | 1 |
| Вартість 1 бала | Розмір знижки за один бал | 0.01 PLN |
| Мін. бали для обміну | Мінімальна кількість балів для обміну | 100 |
| Макс. % знижки | Максимальна відсоткова знижка з балів | 50% |
| Термін дії балів | Через скільки днів бали згоряють | 365 |
| Округлення | floor (вниз) або ceil (вгору) | floor |

## Накопичення балів

Клієнти автоматично отримують бали після виконаного замовлення.

### Пріоритети нарахування

1. **Налаштування для продукту** - поле "Loyalty points per unit" у редагуванні продукту
2. **Налаштування для категорії** - поле в редагуванні категорії продукту
3. **Стандартний розрахунок** - ціна продукту x бали за 1 PLN

### Інформація на сторінці продукту

На сторінці продукту автоматично відображається інформація:
> Отримайте **X балів** за покупку цього продукту

## Обмін балів

Клієнти можуть обміняти бали на знижку на сторінці кошика або оформлення замовлення:
1. Система показує поточний баланс та розмір знижки
2. Клієнт вводить кількість балів для обміну
3. Створюється одноразовий купон зі знижкою
4. Купон автоматично застосовується до кошика

### Обмеження обміну

- Мінімальна кількість балів для обміну (налаштовувана)
- Максимальна знижка як % вартості кошика
- Купон дійсний 24 години

## Панель Мій обліковий запис

У розділі **Мій обліковий запис** з'являється вкладка **Програма лояльності** з:
- Поточний баланс балів та їх вартість у PLN
- Сума накопичених балів
- Сума використаних балів
- Історія транзакцій з датами, типами та деталями

## Термін дії балів

Бали згоряють автоматично через налаштований час (за замовчуванням 365 днів). Cron `polski_daily_maintenance` щодня перевіряє прострочені бали та віднімає їх з балансу.

Налаштування на 0 = бали не згоряють.

## Повернення та скасування

- При скасуванні/поверненні замовлення - нараховані бали автоматично віднімаються
- Захист від подвійного нарахування та віднімання

## Листи замовлень

У листах підтвердження замовлення клієнт бачить інформацію про кількість накопичених балів.

## Хуки

| Хук | Тип | Опис |
|------|-----|------|
| `polski/loyalty/points_awarded` | action | Після нарахування балів за замовлення |
| `polski/loyalty/order_points` | filter | Модифікація кількості балів за замовлення |
