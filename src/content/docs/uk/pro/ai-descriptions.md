Модуль AI-описів продуктів дозволяє автоматично генерувати описи продуктів WooCommerce з використанням будь-якого API, сумісного з OpenAI. Описи оптимізовані під SEO та адаптовані до вибраного тону комунікації.

:::note[Вимоги]
Потрібен ключ API до сервісу, сумісного з OpenAI (наприклад, OpenAI, Azure OpenAI, локальна LLM з endpoint chat/completions).
:::

## Як це працює

1. Адміністратор відкриває редагування продукту WooCommerce
2. У meta box "AI-описи" вибирає мету генерування та тон
3. Плагін надсилає контекст продукту до API
4. Згенерований текст з'являється в meta box для попереднього перегляду
5. Адміністратор приймає або редагує текст перед збереженням

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Polski PRO > AI-описи**.

Налаштування зберігаються в опції:

```
polski_pro_ai_descriptions
```

### Налаштування API

| Налаштування | Опис | Стандартно |
|------------|------|-----------|
| Ключ API | Ключ авторизації до API | - |
| URL API | Endpoint chat/completions | `https://api.openai.com/v1/chat/completions` |
| Модель | Модель AI для генерування | `gpt-4o-mini` |
| Max tokens | Максимальна довжина відповіді | 1024 |

### Налаштування генерування

| Налаштування | Опис | Стандартно |
|------------|------|-----------|
| Тон | Стиль комунікації | professional |
| Мова | Мова згенерованих описів | pl |
| SEO-ключові слова | Враховувати ключові слова в описі | Так |
| Власний prompt | Додаткові інструкції для моделі AI | - |

### Доступні тони

| Тон | Опис |
|-----|------|
| `professional` | Формальний, діловий стиль |
| `casual` | Дружній, розмовний стиль |
| `persuasive` | Переконливий, націлений на продаж |
| `technical` | Детальний, технічний опис специфікацій |
| `luxurious` | Ексклюзивний, аспіраційний стиль преміум |

## Цілі генерування

Meta box на сторінці редагування продукту дозволяє вибрати, який текст має бути згенерований:

| Ціль | Опис |
|-----|------|
| Повний опис | Головний опис продукту (post_content) |
| Короткий опис | Анонс продукту (post_excerpt) |
| SEO-заголовок | Meta-заголовок для пошукових систем |
| SEO meta-опис | Meta description для пошукових систем |

SEO-заголовки та описи автоматично зберігаються в полях відповідного SEO-плагіна (Yoast SEO або RankMath).

## Інтеграція з SEO-плагінами

Модуль виявляє встановлений SEO-плагін і зберігає згенеровані дані у відповідних meta-полях:

### Yoast SEO

- SEO-заголовок зберігається в `_yoast_wpseo_title`
- SEO meta-опис зберігається в `_yoast_wpseo_metadesc`

### RankMath

- SEO-заголовок зберігається в `rank_math_title`
- SEO meta-опис зберігається в `rank_math_description`

Якщо жоден SEO-плагін не активний, опції генерування SEO-заголовка та meta-опису недоступні.

## Контекст продукту

При кожному завданні генерування плагін надсилає до API такі дані продукту:

- **Назва продукту** - заголовок продукту
- **SKU** - каталожний номер
- **Ціна** - звичайна та акційна ціна
- **Категорії** - список категорій продукту
- **Атрибути** - усі атрибути та їхні значення
- **Наявні описи** - поточний повний і короткий опис (якщо існують)

Ці дані дозволяють моделі AI згенерувати влучний і контекстно правильний опис.

## Масове генерування

Модуль підтримує генерування описів для багатьох продуктів одночасно:

1. Перейдіть до **Продукти > Усі продукти**
2. Позначте продукти для генерування
3. Зі списку "Масові дії" виберіть **Генерувати AI-описи**
4. Виберіть мету та тон генерування
5. Натисніть "Застосувати"

Масове генерування працює асинхронно через AJAX - кожен продукт обробляється окремо, а смуга прогресу показує стан операції. Це дозволяє уникнути перевищення тайм-ауту сервера при великій кількості продуктів.

### Ліміти

- Кожне завдання - це окремий виклик API
- Слід враховувати ліміти rate-limiting сервісу API
- При великій кількості продуктів генерування може зайняти кілька хвилин

## Приклад використання

### Генерування опису для одного продукту

1. Відкрийте редагування продукту
2. Прокрутіть до meta box **AI-описи**
3. Виберіть мету: "Повний опис"
4. Виберіть тон: "persuasive"
5. Натисніть **Генерувати**
6. Перегляньте згенерований текст
7. Натисніть **Вставити в опис**, щоб перенести текст до редактора

### Налаштування власного endpoint

Якщо ви користуєтеся локальною моделлю LLM або іншим постачальником:

1. Змініть **URL API** на адресу свого endpoint (має бути сумісний з форматом OpenAI chat/completions)
2. Встановіть відповідну **Модель** (назва моделі, яку розпізнає ваш endpoint)
3. Вкажіть **Ключ API** (якщо потрібен вашим endpoint)

## Увімкнення модуля

Модуль контролюється перемикачем у налаштуваннях модулів PRO:

```
WooCommerce > Налаштування > Polski PRO > Модулі > AI-описи
```
