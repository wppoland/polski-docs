---
title: Вибір дати доставки
description: Модуль вибору бажаної дати доставки на сторінці оформлення замовлення WooCommerce у Polski PRO.
---

Модуль додає поле з календарем (flatpickr) на сторінці замовлення, дозволяючи клієнтам обирати бажану дату доставки.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.3.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Налаштування

Перейдіть до **Polski PRO > Модулі** та увімкніть модуль **Вибір дати доставки**.

| Налаштування | Опис | За замовчуванням |
|------------|------|-----------|
| Підпис поля | Текст, що відображається над календарем | Бажана дата доставки |
| Поле обовʼязкове | Чи має клієнт обрати дату | Ні |
| Мін. дні | Найраніша можлива дата (днів від сьогодні) | 1 |
| Макс. дні | Найпізніша можлива дата (днів від сьогодні) | 30 |
| Заблоковані дні тижня | Які дні недоступні (0=нд, 6=сб) | 0 (неділі) |
| Заблоковані дати | Конкретні недоступні дати (формат: YYYY-MM-DD, розділені комами) | порожнє |
| Формат відображення | Формат дати в замовленні | d.m.Y (l) |

## Як це працює

1. На сторінці оформлення зʼявляється поле з іконкою календаря
2. Клієнт клікає та обирає дату з flatpickr
3. Заблоковані дні (вихідні, свята) затемнені
4. Дата валідується на стороні сервера
5. Зберігається в meta замовлення (`_polski_delivery_date`)

## Де видно дату

- Панель адміністратора (під адресою доставки)
- Сторінка деталей замовлення (Мій обліковий запис)
- Листи замовлення (HTML та plain text)

## Обробка свят

Щоб заблокувати свята (напр. Різдво, Великдень), додайте дати у форматі YYYY-MM-DD, розділені комами:

```
2026-12-25,2026-12-26,2026-04-05,2026-04-06,2026-05-01,2026-05-03
```

## WooCommerce Blocks

Модуль також підтримує оформлення замовлення на основі блоків WooCommerce. Дата передається через Store API в `extensions.polski-pro.delivery_date`.
