Модуль виконання замовлень розширює типові статуси WooCommerce трьома додатковими етапами: **Спаковано**, **Відправлено** та **Доставлено**. Кожна зміна статусу надсилає автоматичний лист клієнту з інформацією про відстеження.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.3.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Нові статуси замовлень

Після увімкнення модуля замовлення можуть проходити через такі статуси:

```
Очікувані > Опрацьовувані > Спаковано > Відправлено > Доставлено > Завершено
```

| Статус | Колір | Опис |
|--------|-------|------|
| Спаковано (Packed) | Синій | Замовлення спаковано й очікує на отримання курʼєром |
| Відправлено (Shipped) | Жовтий | Посилка передана курʼєру, у транспортуванні |
| Доставлено (Delivered) | Зелений | Посилка доставлена клієнту |

Статуси зʼявляються в панелі замовлень між "Опрацьовувані" та "Завершено".

## Налаштування

1. Перейдіть до **Polski PRO > Модулі**
2. Увімкніть модуль **Виконання замовлень**

Модуль не потребує додаткового налаштування, статуси, поле відстеження та листи готові одразу.

## Поле відстеження посилки

У редакторі замовлення, під адресою доставки, зʼявляється секція **Shipment Tracking**:

| Поле | Опис |
|------|------|
| Перевізник | Вибір: InPost, DPD, DHL, Poczta Polska, Інший |
| Номер відстеження | Номер транспортної накладної |
| URL відстеження | Генерується автоматично на основі перевізника та номера |

Після вибору перевізника та введення номера відстеження посилання на трекінг генерується автоматично. Можна також ввести власний URL вручну.

### Автоматичні посилання для відстеження

| Перевізник | Формат URL |
|------------|-----------|
| InPost | `inpost.pl/sledzenie-przesylek?number={numer}` |
| DPD | `tracktrace.dpd.com.pl/findPackage?q={numer}` |
| DHL | `dhl.com/pl-pl/home/sledzenie-przesylek.html?tracking-id={numer}` |
| Poczta Polska | `emonitoring.poczta-polska.pl/?numer={numer}` |

## Email-сповіщення

При кожній зміні статусу система надсилає лист клієнту з:

- Номером замовлення
- Новим статусом
- Назвою перевізника (якщо встановлена)
- Номером відстеження (якщо встановлений)
- Посиланням на відстеження посилки
- Посиланням на перегляд замовлення в Мій обліковий запис

Листи надсилаються автоматично, не потребують ручної дії.

## Масові дії

У списку замовлень доступні масові дії:

- **Змінити статус на Спаковано**
- **Змінити статус на Відправлено**
- **Змінити статус на Доставлено**

Позначте кілька замовлень і виберіть дію з випадного меню.

## Сумісність

Модуль працює з:

- WooCommerce HPOS (Custom Order Tables)
- WooCommerce класичними замовленнями (posts)
- Усіма темами WooCommerce
- Курʼєрськими інтеграціями Polski PRO (InPost, DPD, DHL)

Статуси видимі також у REST API WooCommerce та у звітах.
