Модуль Poczta Polska інтегрує WooCommerce з API eNadawca. Генеруйте етикетки відправлень, відстежуйте посилки та шукайте поштові автомати.

:::note[Вимоги]
Polski PRO потребує: Polski (free) v1.3.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+ з розширенням SOAP. Додатково потрібні логін і пароль до eNadawca.
:::

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Polski PRO > Доставка**.

### Автентифікація

| Налаштування | Опис |
|------------|------|
| Логін eNadawca | Логін до системи eNadawca |
| Пароль eNadawca | Пароль до системи eNadawca |
| Середовище | Production або Sandbox (тестове) |

Дані доступу отримаєте, зареєструвавшись у системі eNadawca на сайті poczta-polska.pl.

## Доступні послуги

| Тип послуги | Опис |
|------------|------|
| POCZTEX_KURIER_48 | Кур'єр Pocztex - доставка за 48 год (типова) |
| PACZKA_POCZTOWA_GABARYT_A | Поштова посилка габарит A |

## Генерація етикеток

1. Відкрийте замовлення в **WooCommerce > Замовлення**
2. У секції **Shipment Tracking** виберіть перевізника **Poczta Polska**
3. Натисніть **Згенерувати етикетку**
4. Система створить відправлення через eNadawca SOAP API

Дані одержувача (ім'я, адреса, місто, поштовий індекс, телефон, email) беруться автоматично із замовлення.

## Відстеження відправлень

Після генерації етикетки номер відстеження зберігається в замовленні. Посилання на трекінг:

```
https://emonitoring.poczta-polska.pl/?numer={numer}
```

## Поштові автомати

Модуль дозволяє шукати поштові автомати та відділення Poczta Polska за містом.

## Технічні вимоги

Модуль потребує розширення PHP SOAP (`ext-soap`). Перевірте, чи воно активне:

```php
phpinfo(); // Шукай секцію "soap"
```

Більшість хостингів PHP має SOAP увімкненим за замовчуванням.
