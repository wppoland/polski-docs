Модуль Tpay інтегрує WooCommerce з одним із найпопулярніших польських платіжних шлюзів.

:::note[Вимоги]
Polski PRO потребує: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+. Акаунт у Tpay.
:::

## Підтримувані методи

| Метод | Опис |
|--------|------|
| Банківські перекази | Усі польські банки онлайн |
| BLIK | Оплата 6-значним кодом |
| Платіжні картки | Visa, Mastercard |

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Оплата > Tpay**.

| Налаштування | Опис |
|------------|------|
| Merchant ID | ID продавця Tpay (4-5 цифр) |
| Security code | Код безпеки |
| API key | 40-символьний ключ API (для повернень) |
| API password | Пароль API |
| BLIK | Увімкнути платежі BLIK |
| Список банків | Показати на сторінці оформлення або перенаправити до Tpay |

## Доплата за оплату

Можна налаштувати доплату за використання шлюзу:
- Стала сума (PLN)
- Відсоток вартості замовлення

## Верифікація IPN

Сповіщення IPN верифікуються через:
1. Контрольну суму MD5: `md5(merchant_id + transaction_id + amount + crc + security_code)`
2. Білий список IP Tpay (5 адрес)

## Повернення

Повернення обробляються через Tpay Transaction API. Потрібен ключ API і пароль.
