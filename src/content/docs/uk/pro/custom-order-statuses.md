Модуль дозволяє створювати будь-які статуси замовлень WooCommerce з налаштовуваним виглядом та автоматичними листами.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Налаштування

Перейдіть до **WooCommerce > Order Statuses**.

## Створення статусу

| Поле | Опис |
|------|------|
| Slug | Ідентифікатор статусу (макс. 17 символів, напр. quality_check) |
| Label | Відображувана назва (напр. "Контроль якості") |
| Color | Колір фону бейджа статусу (hex) |
| Icon | Клас dashicon (напр. dashicons-yes) |
| Email | Чи надсилати лист при зміні на цей статус |
| Email subject | Тема листа (підтримує токени) |
| Email body | Вміст листа HTML (підтримує токени) |

## Токени в листах

| Токен | Опис |
|-------|------|
| `{order_id}` | ID замовлення |
| `{order_number}` | Номер замовлення |
| `{first_name}` | Імʼя клієнта |
| `{last_name}` | Прізвище клієнта |
| `{status_from}` | Попередній статус |
| `{status_to}` | Новий статус |
| `{site_title}` | Назва магазину |

## Функції

- Статуси видимі у випадному списку зміни статусу замовлення
- Кольорові бейджі у списку замовлень
- Масові дії (bulk actions) для кожного статусу
- Автоматичні листи WooCommerce (загорнуті в шаблон)
- Необмежена кількість статусів
