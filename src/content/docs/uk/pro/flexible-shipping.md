---

Метод доставки Flexible Shipping дозволяє визначати складні правила вартості доставки.

:::note[Вимоги]
Polski PRO вимагає: Polski (free) v1.5.0+, WordPress 6.4+, WooCommerce 8.0+, PHP 8.1+.
:::

## Налаштування

Перейдіть до **WooCommerce > Налаштування > Доставка > [Зона] > Додати метод > Flexible Shipping**.

## Умови правил

| Умова | Опис |
|---------|------|
| Мін/макс вартість кошика | Вартість залежить від суми замовлення |
| Мін/макс вага | Вартість залежить від ваги кошика (кг) |
| Мін/макс кількість продуктів | Вартість залежить від кількості |
| Країни | Правило лише для визначених країн |

## Режими розрахунку вартості

| Режим | Опис |
|------|------|
| fixed | Фіксована сума за замовлення |
| per_item | Сума x кількість продуктів |
| per_kg | Сума x вага в кг |
| percent | Відсоток вартості кошика |

## Додаткова вартість за вагу

Можна налаштувати додаткову вартість за кожен кг понад поріг:
- `extra_kg_above`: Ваговий поріг (кг)
- `extra_kg_cost`: Вартість за додатковий кг

## Безкоштовна доставка

Поле "Free shipping above" - після перевищення вартості кошика доставка стає безкоштовною.

## Правила JSON

Правила зберігаються як JSON. Приклад:

```json
[
  {
    "label": "Standard (do 5 kg)",
    "min_weight": 0,
    "max_weight": 5,
    "cost_type": "fixed",
    "cost": 12.99
  },
  {
    "label": "Ciezka paczka",
    "min_weight": 5,
    "max_weight": 30,
    "cost_type": "fixed",
    "cost": 19.99,
    "extra_kg_above": 10,
    "extra_kg_cost": 2
  }
]
```
