Polski PRO for WooCommerce це платне розширення безкоштовного плагіна Polski for WooCommerce. Додає преміум-модулі: виставлення рахунків, KSeF, багатоетапне оформлення замовлення, подарункові картки, підписки та партнерську програму.

## Що додає версія PRO

Безкоштовна версія охоплює основи: поля NIP, правові чекбокси, ціни за одиницю, VAT та Omnibus. Версія PRO додає понад десяток модулів:

| Модуль | Опис |
|-------|------|
| [Рахунки](/pro/invoices/) | Система рахунків VAT, коригувальних, чеків та документів WZ з генеруванням PDF |
| [Інтеграція KSeF](/pro/ksef/) | Надсилання електронних рахунків до Krajowy System e-Faktur |
| [Багатоетапне оформлення](/pro/multistep-checkout/) | Поділ процесу замовлення на кроки: адреса, доставка, оплата, підсумок |
| [Керування згодами](/pro/consent-management/) | Версіонування згод, audit trail, експорт CSV/JSON, інтеграція RODO |
| [Виконання замовлень](/pro/fulfillment/) | Статуси Спаковано/Відправлено/Доставлено, поле відстеження, листи клієнту |
| [InPost](/pro/shipping-inpost/) | Поштомати, етикетки, карта пунктів видачі, відстеження |
| [DPD](/pro/shipping-dpd/) | Етикетки, відстеження, пункти DPD Pickup |
| [DHL](/pro/shipping-dhl/) | Етикетки, відстеження, ServicePoint |
| [Подарункові картки](/pro/gift-cards/) | Продаж подарункових карток, генерування кодів, реалізація в кошику |
| [Підписки](/pro/subscriptions/) | Регулярні платежі, поновлення, нагадування за 14 та 7 днів, скасування одним кліком |
| [Партнерська програма](/pro/affiliates/) | Реферальні посилання, відстеження комісій, панель партнера |
| [Bundles та Add-ons](/pro/bundles-addons/) | Пакети продуктів, додаткові опції для продукту |
| [Запити пропозицій](/pro/quotes/) | Форма пропозицій, панель керування |
| [Передпродаж (pre-orders)](/pro/preorders/) | Продаж продуктів до їх доступності |
| [Каталожний режим](/pro/catalog-mode/) | Приховування цін та кошика (B2B) |
| [Бухгалтерські інтеграції](/pro/accounting/) | wFirma, Fakturownia, iFirma |

Кожен модуль можна увімкнути або вимкнути незалежно в налаштуваннях плагіна.

Плагін PRO вимагає активної безкоштовної версії 1.3.0 або новішої. Встановіть та оновіть її перед встановленням PRO.

## Встановлення

### Крок 1 - завантажте файл ZIP

Після придбання ліцензії на [wppoland.com/pl/polski-pro](https://wppoland.com/pl/polski-pro/) завантажте файл ZIP плагіна з панелі клієнта.

### Крок 2 - встановіть плагін

1. Перейдіть до **Плагіни > Додати новий > Завантажити плагін на сервер**
2. Виберіть завантажений файл ZIP
3. Натисніть **Встановити зараз**
4. Після встановлення натисніть **Активувати плагін**

### Крок 3 - активуйте ліцензію

1. Перейдіть до **WooCommerce > Налаштування > Polski > Ліцензія PRO**
2. Введіть ліцензійний ключ, отриманий після придбання
3. Натисніть **Активувати ліцензію**
4. Після успішної активації з'явиться зелене повідомлення з датою закінчення ліцензії

Ключ прив'язаний до домену. При зміні домену спочатку деактивуйте ліцензію на старому, потім активуйте на новому.

### Крок 4 - увімкніть модулі

Після активації ліцензії перейдіть до **WooCommerce > Налаштування > Polski > Модулі PRO** і увімкніть вибрані модулі. Кожен модуль має власну секцію налаштувань, описану в окремій документації.

## Оновлення

Після активації ліцензії плагін оновлюється як будь-який інший плагін WordPress:

1. Повідомлення про доступне оновлення з'явиться в панелі **Плагіни**
2. Натисніть **Оновити зараз**
3. Плагін оновиться автоматично

Без активної ліцензії плагін працює, але не отримує оновлень.
