GDPR (RODO) вимагає від магазинів отримання чіткої згоди на обробку персональних даних. Плагін додає 7 налаштовуваних чекбоксів на сторінці замовлення, логування згод та інструменти для керування згодами.

## Необхідні згоди в польському e-commerce

Інтернет-магазин повинен збирати згоди на:

1. Прийняття правил магазину
2. Ознайомлення з політикою конфіденційності
3. Право на відмову від договору (підтвердження ознайомлення)
4. Згоду на надання цифрового контенту до закінчення терміну відмови
5. Сповіщення про доставку (SMS/e-mail)
6. Нагадування про відгук
7. Маркетинг (розсилка, комерційні пропозиції)

## Налаштування чекбоксів

Перейдіть до **WooCommerce > Налаштування > Polski > GDPR** і налаштуйте згоди.

### 1. Правила магазину

Обов'язковий чекбокс із посиланням на сторінку правил.

| Налаштування | Опис |
|------------|------|
| Текст | Налаштовуваний, за замовчуванням: "Я ознайомився(лась) з [правилами] та приймаю їх умови" |
| Обов'язковий | Так (завжди) |
| Сторінка правил | Виберіть зі сторінок WordPress |

### 2. Політика конфіденційності

Обов'язковий чекбокс із посиланням на політику конфіденційності.

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я ознайомився(лась) з [політикою конфіденційності]" |
| Обов'язковий | Так (завжди) |
| Сторінка політики | Виберіть зі сторінок WordPress |

### 3. Право на відмову від договору

Інформація про ознайомлення з умовами відмови.

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я ознайомився(лась) з умовами [відмови від договору]" |
| Обов'язковий | Так |
| Сторінка відмови | Виберіть зі сторінок WordPress |

### 4. Цифровий контент

Згода, необхідна при продажу цифрового контенту (наприклад, електронні книги, файли для завантаження).

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я даю згоду на надання цифрового контенту до закінчення терміну відмови від договору та приймаю до відома втрату права на відмову" |
| Обов'язковий | Так (коли кошик містить цифрові продукти) |
| Умова | Відображати лише коли кошик містить віртуальні продукти або продукти для завантаження |

### 5. Сповіщення про доставку

Згода на надсилання сповіщень SMS/e-mail про статус відправлення.

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я даю згоду на отримання сповіщень про статус доставки" |
| Обов'язковий | Ні |
| Канал | E-mail, SMS або обидва |

### 6. Нагадування про відгук

Згода на надсилання листа з проханням залишити відгук після покупки.

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я даю згоду на отримання листа з проханням залишити відгук про придбаний продукт" |
| Обов'язковий | Ні |
| Затримка | Кількість днів після доставки (за замовчуванням 7) |

### 7. Маркетинг

Згода на маркетингову комунікацію.

| Налаштування | Опис |
|------------|------|
| Текст | За замовчуванням: "Я даю згоду на отримання комерційної інформації електронними засобами" |
| Обов'язковий | Ні |
| Обсяг | Розсилка, пропозиції, акції |

## Логування згод

Кожна згода зберігається в базі даних з даними:

| Поле | Опис |
|------|------|
| ID користувача | ID клієнта WordPress (або 0 для гостей) |
| ID замовлення | Номер замовлення WooCommerce |
| Тип згоди | Ідентифікатор чекбокса (наприклад, `terms`, `privacy`, `marketing`) |
| Значення | `granted` або `denied` |
| IP-адреса | Анонімізована IP-адреса клієнта |
| User Agent | Браузер та операційна система |
| Часова мітка | Дата і час надання згоди (UTC) |
| Версія документа | Hash версії правил/політики на момент надання згоди |

### Перегляд логів згод

Логи згод доступні в:

- **Замовлення WooCommerce** - вкладка "Згоди GDPR" у бічній панелі замовлення
- **Профіль користувача** - розділ "Історія згод" у профілі клієнта в адміністративній панелі
- **Експорт** - можливість експорту логів у CSV (**WooCommerce > Налаштування > Polski > GDPR > Експортувати логи**)

### Анонімізація IP

Плагін анонімізує останній октет адреси IPv4 (наприклад, `192.168.1.xxx`) та останню групу IPv6. Це забезпечує відповідність GDPR та зберігає базову корисність логів.

## Shortcode API

### Відображення статусу згод клієнта

```
[polski_consent_status]
```

Показує авторизованому клієнту список згод з можливістю їх відкликання (наприклад, маркетингова згода).

### Форма відкликання маркетингової згоди

```
[polski_consent_withdraw type="marketing"]
```

Форма для відкликання маркетингової згоди. Після відкликання плагін автоматично оновлює статус згоди в базі даних.

### Параметри shortcode

| Параметр | Опис | Доступні значення |
|----------|------|-------------------|
| `type` | Тип згоди | `terms`, `privacy`, `withdrawal_right`, `digital_content`, `delivery_notifications`, `review_reminder`, `marketing` |

## Інтеграція з WooCommerce Blocks

Чекбокси згод працюють також із блочною формою замовлення (WooCommerce Blocks Checkout). Нічого налаштовувати не потрібно.

## Право бути забутим

Плагін працює разом з інструментом WordPress **Інструменти > Видалити персональні дані**. Після затвердження запиту на видалення плагін автоматично:

1. Анонімізує дані в логах згод
2. Видаляє персональні дані з форм відмови
3. Зберігає анонімізовані записи для цілей підзвітності

## Право на перенесення даних

Плагін працює разом з **Інструменти > Експортувати персональні дані**. Експорт містить:

- Історію наданих згод
- Дані з форм (анонімізовані)
- Комунікаційні налаштування

## Усунення проблем

**Чекбокси не відображаються на сторінці замовлення**
Перевірте, чи модуль GDPR увімкнено в **WooCommerce > Налаштування > Polski > Модулі**. При блочній формі замовлення потрібен WooCommerce 8.0+.

**Клієнт повідомляє про неможливість оформити замовлення**
Перевірте, чи інший плагін (наприклад, Germanized, WPML) не додає ті самі чекбокси. Вимкніть згоди з інших плагінів і використовуйте лише модуль Polski for WooCommerce.

**Логи згод не зберігають IP-адресу**
Перевірте, чи сервер передає IP-адресу. За reverse proxy (наприклад, Cloudflare) налаштуйте заголовок `X-Forwarded-For` у WordPress.
