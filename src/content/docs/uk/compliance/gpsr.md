Регламент GPSR (General Product Safety Regulation, EU 2023/988) діє з 13 грудня 2024 року. Він вимагає надання інформації про безпеку продуктів, що продаються в ЄС. Polski for WooCommerce додає поля продуктів, колонку статусу та імпорт/експорт CSV, усе, що вам потрібно, без додаткових плагінів.

## Вимоги GPSR

Кожен непродовольчий продукт, що продається в ЄС, повинен містити:

1. **Дані виробника** - назва, адреса, контактні дані
2. **Дані імпортера** - якщо виробник має осідок за межами ЄС
3. **Відповідальна особа в ЄС** - вимагається для продуктів з-поза ЄС
4. **Ідентифікатори продукту** - номер партії, серійний номер, код EAN/GTIN
5. **Попередження** - інформація про загрози та вікові обмеження
6. **Інструкції з безпеки** - правила безпечного використання
7. **Фото/документи** - необов'язкові додатки (картки характеристик, сертифікати)
8. **Категорія ризику** - класифікація рівня ризику продукту

## Налаштування полів GPSR

Поля GPSR знайдете в редагуванні продукту, у вкладці **Polski - GPSR**. Кожне поле необов'язкове, але заповніть усі, що стосуються конкретного продукту.

![Поля GPSR у редакторі продукту WooCommerce](../../../../assets/screenshots/screenshot-2-gpsr-product-editor.png)

### Виробник

Заповніть повні дані виробника:

- Назва компанії
- Адреса (вулиця, поштовий індекс, місто, країна)
- Адреса електронної пошти
- Номер телефону
- Вебсайт

### Імпортер

Вимагається, коли виробник має осідок за межами ЄС. Вкажіть ті самі дані, що й для виробника.

### Відповідальна особа в ЄС

Кожен непродовольчий продукт від суб'єкта з-поза ЄС повинен мати відповідальну особу з осідком у Союзі. Вкажіть:

- Назва компанії або ім'я та прізвище
- Адреса в ЄС
- Контактні дані (e-mail, телефон)

### Ідентифікатори продукту

- **Номер партії (LOT)** - ідентифікатор виробничої партії
- **Серійний номер** - унікальний ідентифікатор екземпляра
- **EAN/GTIN** - штрих-код продукту
- **Номер моделі** - позначення моделі

### Попередження та обмеження

Текстове поле для інформації про:

- Загрози, пов'язані з використанням
- Вікові обмеження (наприклад, "Не підходить для дітей до 3 років")
- Вимоги щодо нагляду дорослої особи
- Небезпечні речовини

### Інструкції з безпеки

Поле для інструкцій щодо:

- Правильного монтажу та встановлення
- Безпечного використання
- Догляду та зберігання
- Дій у разі нещасного випадку

## Колонка статусу GPSR

У списку продуктів (**Продукти > Усі продукти**) плагін додає колонку **GPSR** зі статусом заповнення:

- Зелена іконка - усі обов'язкові поля заповнено
- Помаранчева іконка - заповнено частково
- Червона іконка - немає даних GPSR

Колонка дозволяє швидко знайти продукти, що потребують доповнення даних.

## Імпорт та експорт CSV

### Експорт

При експорті продуктів (**Продукти > Експортувати**) плагін додає колонки GPSR до файлу CSV:

- `gpsr_manufacturer_name`
- `gpsr_manufacturer_address`
- `gpsr_manufacturer_email`
- `gpsr_manufacturer_phone`
- `gpsr_manufacturer_url`
- `gpsr_importer_name`
- `gpsr_importer_address`
- `gpsr_importer_email`
- `gpsr_eu_responsible_name`
- `gpsr_eu_responsible_address`
- `gpsr_eu_responsible_email`
- `gpsr_identifiers_lot`
- `gpsr_identifiers_serial`
- `gpsr_identifiers_ean`
- `gpsr_identifiers_model`
- `gpsr_warnings`
- `gpsr_instructions`

### Імпорт

Підготуйте файл CSV з такими самими заголовками, як при експорті. Імпортуйте через **Продукти > Імпортувати**.

Підказка: спершу експортуйте кілька продуктів, отримаєте шаблон CSV з правильними заголовками.

## Shortcode

Використовуйте shortcode `[polski_gpsr]` для відображення інформації GPSR на сторінці продукту або в будь-якому місці сайту.

### Базове використання

```
[polski_gpsr]
```

Відображає дані GPSR поточного продукту (працює на сторінці продукту WooCommerce).

### Із зазначенням продукту

```
[polski_gpsr product_id="123"]
```

Відображає дані GPSR для продукту із зазначеним ID.

### Приклад результату

Shortcode генерує форматовану таблицю з розділами:

| Розділ | Зміст |
|--------|-----------|
| Виробник | Назва, адреса, e-mail, телефон, вебсайт |
| Імпортер | Назва, адреса, e-mail (якщо стосується) |
| Відповідальна особа в ЄС | Назва, адреса, контактні дані |
| Ідентифікатори | LOT, серійний номер, EAN, модель |
| Попередження | Текст попереджень |
| Інструкції | Текст інструкцій з безпеки |

## Масове доповнення даних

Якщо багато продуктів мають того самого виробника, найшвидший метод це:

1. Експортуйте продукти в CSV
2. Заповніть колонки виробника для всіх рядків (копіювати-вставити в електронній таблиці)
3. Імпортуйте оновлений файл CSV

## Усунення проблем

**Поля GPSR не з'являються в редагуванні продукту**
Переконайтеся, що модуль GPSR увімкнено в налаштуваннях плагіна: **WooCommerce > Налаштування > Polski > Модулі**.

**Колонка статусу не відображається у списку продуктів**
Натисніть кнопку "Параметри екрана" у правому верхньому куті сторінки зі списком продуктів та позначте колонку GPSR.

**Дані не імпортуються з CSV**
Перевірте, чи заголовки колонок у файлі CSV точно відповідають формату експорту. Назви колонок чутливі до регістру.
