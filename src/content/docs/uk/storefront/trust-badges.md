---

Значки довіри - це графічні елементи, що інформують клієнтів про безпечні платежі, швидку доставку, можливість повернення та гарантію якості. Допомагають підвищити конверсію, формуючи довіру в ключові моменти шляху покупки.

## Увімкнення модуля

Перейдіть до **WooCommerce > Polski > Модулі магазину** та увімкніть **Значки довіри**. Іконки з'являться автоматично на сторінках товару, кошика та замовлення.

## Функції

- Налаштовувані сигнали довіри з вбудованими SVG-іконками
- Відображення на сторінках товару, кошика та підсумку замовлення
- 7 типів іконок: замок (lock), вантажівка (truck), оновлення (refresh), щит (shield), зірочка (star), галочка (check), серце (heart)
- Власні тексти під кожним значком
- Чистий CSS без зовнішніх залежностей
- Адаптивне розташування на мобільних пристроях

## Налаштування

Конфігурація в **WooCommerce > Polski > Модулі магазину > Значки довіри**.

| Налаштування | За замовчуванням | Опис |
|---|---|---|
| `show_on_product` | `true` | Відображати значки на сторінці товару |
| `show_on_cart` | `true` | Відображати значки на сторінці кошика |
| `show_on_checkout` | `true` | Відображати значки на сторінці замовлення |

Кожен значок можна індивідуально увімкнути/вимкнути та налаштувати:

- **Іконка** - вибір із 7 доступних типів
- **Заголовок** - короткий текст під іконкою (наприклад, "Безпечна оплата")
- **Порядок** - позиція відносно інших значків

Опція в базі даних: `polski_trust_badges`.

## Стандартні значки

Після увімкнення модуля доступні 4 попередньо визначені значки:

| Значок | Іконка | Стандартний текст |
|---|---|---|
| Безпечна оплата | lock | Шифроване з'єднання SSL |
| Швидка доставка | truck | Відправлення за 24 год |
| Повернення | refresh | 14 днів на повернення |
| Гарантія якості | shield | Оригінальні товари |

## Технічні деталі

### SVG-іконки

Усі іконки відображаються як вбудовані SVG - без HTTP-запитів, без залежностей від бібліотек іконок. Кожна іконка має розмір 32x32px і успадковує колір із CSS.

### Хуки

```php
// Фільтрувати список значків
add_filter('polski/trust_badges/items', function (array $badges): array {
    // Додати власний значок
    $badges[] = [
        'icon'  => 'star',
        'title' => 'Понад 1000 відгуків',
    ];
    return $badges;
});

// Змінити позицію на сторінці товару
add_filter('polski/trust_badges/product_hook', function (): string {
    return 'woocommerce_after_add_to_cart_form'; // за замовчуванням: woocommerce_product_meta_end
});
```

### CSS-класи

- `.polski-trust-badges` - головний контейнер
- `.polski-trust-badge` - окремий значок
- `.polski-trust-badge__icon` - SVG-іконка
- `.polski-trust-badge__title` - текст під іконкою

```css
.polski-trust-badges {
    display: flex;
    gap: 1rem;
    justify-content: center;
    padding: 1rem 0;
    border-top: 1px solid #e5e7eb;
}
```

### ID модуля

`trust_badges`

## Усунення несправностей

**Значки не відображаються** - перевірте, чи підтримує тема хуки WooCommerce на сторінці товару (`woocommerce_product_meta_end`) і кошика (`woocommerce_after_cart_totals`).

**Іконки занадто малі/занадто великі** - перевизначте розмір у CSS: `.polski-trust-badge__icon svg { width: 40px; height: 40px; }`.
