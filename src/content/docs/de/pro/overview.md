Polski PRO for WooCommerce ist eine kostenpflichtige Erweiterung des kostenlosen Plugins Polski for WooCommerce. Es ergänzt Premium-Module: Rechnungsstellung, KSeF, mehrstufige Kasse, Geschenkkarten, Abonnements und ein Partnerprogramm.

## Was die PRO-Version ergänzt

Die kostenlose Version deckt die Grundlagen ab: NIP-Felder, rechtliche Checkboxen, Grundpreise, USt und Omnibus. Die PRO-Version ergänzt rund ein Dutzend Module:

| Modul | Beschreibung |
|-------|------|
| [Rechnungen](/pro/invoices/) | System für USt-Rechnungen, Korrekturrechnungen, Belege und Lieferscheine (WZ) mit PDF-Erzeugung |
| [KSeF-Integration](/pro/ksef/) | Versand elektronischer Rechnungen an das nationale e-Rechnungssystem KSeF |
| [Mehrstufiger Checkout](/pro/multistep-checkout/) | Aufteilung des Bestellvorgangs in Schritte: Adresse, Versand, Zahlung, Zusammenfassung |
| [Einwilligungsverwaltung](/pro/consent-management/) | Versionierung von Einwilligungen, Audit Trail, CSV/JSON-Export, DSGVO-Integration |
| [Auftragsabwicklung](/pro/fulfillment/) | Status Verpackt/Versendet/Zugestellt, Sendungsverfolgungsfeld, E-Mails an den Kunden |
| [InPost](/pro/shipping-inpost/) | Paketautomaten, Etiketten, Karte der Abholpunkte, Sendungsverfolgung |
| [DPD](/pro/shipping-dpd/) | Etiketten, Sendungsverfolgung, DPD Pickup-Punkte |
| [DHL](/pro/shipping-dhl/) | Etiketten, Sendungsverfolgung, ServicePoint |
| [Geschenkkarten](/pro/gift-cards/) | Verkauf von Geschenkkarten, Code-Erzeugung, Einlösung im Warenkorb |
| [Abonnements](/pro/subscriptions/) | Wiederkehrende Zahlungen, Verlängerungen, Erinnerungen 14 und 7 Tage vorher, Kündigung mit einem Klick |
| [Partnerprogramm](/pro/affiliates/) | Empfehlungslinks, Provisionsverfolgung, Partner-Panel |
| [Bundles und Add-ons](/pro/bundles-addons/) | Produktpakete, zusätzliche Optionen pro Produkt |
| [Angebotsanfragen](/pro/quotes/) | Angebotsformular, Verwaltungspanel |
| [Vorbestellungen](/pro/preorders/) | Verkauf von Produkten vor der Verfügbarkeit |
| [Katalogmodus](/pro/catalog-mode/) | Ausblenden von Preisen und Warenkorb (B2B) |
| [Buchhaltungs-Integrationen](/pro/accounting/) | wFirma, Fakturownia, iFirma |

Jedes Modul lässt sich unabhängig in den Plugin-Einstellungen aktivieren oder deaktivieren.

## Systemvoraussetzungen

| Voraussetzung | Mindestversion |
|-----------|-----------------|
| Polski for WooCommerce (free) | 1.3.0 |
| WordPress | 6.4 |
| WooCommerce | 8.0 |
| PHP | 8.1 |

Das PRO-Plugin erfordert eine aktive kostenlose Version 1.3.0 oder neuer. Installieren und aktualisieren Sie diese vor der Installation von PRO.

## Installation

### Schritt 1 - ZIP-Datei herunterladen

Nach dem Kauf einer Lizenz auf [wppoland.com/pl/polski-pro](https://wppoland.com/pl/polski-pro/) laden Sie die ZIP-Datei des Plugins aus dem Kundenbereich herunter.

### Schritt 2 - Plugin installieren

1. Gehen Sie zu **Plugins > Installieren > Plugin hochladen**
2. Wählen Sie die heruntergeladene ZIP-Datei aus
3. Klicken Sie auf **Jetzt installieren**
4. Klicken Sie nach der Installation auf **Plugin aktivieren**

### Schritt 3 - Lizenz aktivieren

1. Gehen Sie zu **WooCommerce > Einstellungen > Polski > PRO-Lizenz**
2. Geben Sie den nach dem Kauf erhaltenen Lizenzschlüssel ein
3. Klicken Sie auf **Lizenz aktivieren**
4. Nach erfolgreicher Aktivierung erscheint eine grüne Meldung mit dem Ablaufdatum der Lizenz

Der Schlüssel ist an die Domain gebunden. Bei einem Domainwechsel deaktivieren Sie zuerst die Lizenz auf der alten Domain und aktivieren sie dann auf der neuen.

### Schritt 4 - Module aktivieren

Nach der Lizenzaktivierung gehen Sie zu **WooCommerce > Einstellungen > Polski > PRO-Module** und aktivieren die gewünschten Module. Jedes Modul hat einen eigenen Konfigurationsbereich, der in der jeweiligen Dokumentation beschrieben ist.

## Aktualisierungen

Nach der Lizenzaktivierung aktualisiert sich das Plugin wie jedes andere WordPress-Plugin:

1. Eine Benachrichtigung über eine verfügbare Aktualisierung erscheint im Bereich **Plugins**
2. Klicken Sie auf **Jetzt aktualisieren**
3. Das Plugin aktualisiert sich automatisch

Ohne aktive Lizenz funktioniert das Plugin, erhält jedoch keine Aktualisierungen.
